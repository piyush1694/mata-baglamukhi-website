# Maa Baglamukhi Website

A responsive static website featuring a brief devotional story and information about Havan Anusthan, donations and Langar Seva.

## Run locally

Open `index.html` in a browser. No build step or package installation is needed.

The hero image is hosted by Wikimedia Commons. Its creator is Rohit2301 and it is published under CC0: https://commons.wikimedia.org/wiki/File:Maa-bagllamukhi-mata-bankhandi.jpg

Seva enquiries open an email draft to the trust. The website does not collect payments or confirm bookings; contact the trust directly for arrangements.
